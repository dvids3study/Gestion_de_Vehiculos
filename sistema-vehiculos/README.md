# Sistema de Vehículos

Aplicación web para la consulta y administración interna de vehículos usados.

El sistema permite gestionar inventario, ubicación de vehículos, documentación,
pico y placa, usuarios, historial de movimientos y citas comerciales.

## Características principales

- Consulta de inventario
- Gestión de ubicación de vehículos
- Administración de usuarios
- Control de roles
- Gestión de citas
- Alertas de citas próximas y atrasadas
- Historial de movimientos
- Consulta de documentación
- Pico y placa
- Interfaz responsive
- Persistencia de módulo activo durante recarga

## Tecnologías

- Google Apps Script
- HTML
- CSS
- JavaScript
- Google Sheets
- Lottie
